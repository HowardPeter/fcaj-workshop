### Week 1 Objectives:

* Gain hands-on experience with AWS services for compute, databases, containers, and networking.
* Practice deploying, scaling, monitoring, and managing AWS resources.

### Tasks to be carried out this week:

| Day | Task | Start Date | Completion Date | Reference Material |
| --- | --- | --- | --- | --- |
| 1 | - Explore AWS CloudShell and its built-in command-line environment. <br> - Practice executing AWS CLI commands and managing resources through CloudShell. | 10/05/2026 | 10/05/2026 | [AWS CloudShell](https://000049.awsstudygroup.com/) |
| 2 | - Learn about Amazon RDS and managed relational databases. <br> - **Practice:** Create and configure an RDS database instance and explore database connectivity. | 10/06/2026 | 10/06/2026 | [Amazon RDS](https://000005.awsstudygroup.com/) |
| 3 | - Explore Amazon Lightsail and its simplified cloud infrastructure management. <br> - **Practice:** Deploy applications, configure networking, and explore security, backups, and resource scaling. | 10/07/2026 | 10/07/2026 | [Amazon Lightsail](https://000045.awsstudygroup.com/) |
| 4 | - Learn about container deployment with Amazon Lightsail Containers. <br> - **Practice:** Build a Docker image, push the image, and deploy a containerized application using Lightsail. | 10/08/2026 | 10/08/2026 | [Lightsail Containers](https://000046.awsstudygroup.com/) |
| 5 | - Learn about EC2 Auto Scaling, load balancing, and hybrid DNS resolution with Route 53. <br> - **Practice:** Configure an Auto Scaling environment and set up Route 53 Resolver endpoints and forwarding rules. | 10/09/2026 | 10/09/2026 | [EC2 Auto Scaling](https://000006.awsstudygroup.com/) <br> [Hybrid DNS with Route 53](https://000010.awsstudygroup.com/) |

### Week 1 Achievements:

* Became familiar with AWS CloudShell and practiced managing cloud resources using AWS CLI.
* Gained practical experience with Amazon RDS, including database provisioning and connectivity.
* Deployed applications using Amazon Lightsail and explored security, backup, and scaling configurations.
* Built and deployed container images using Amazon Lightsail Containers.
* Practiced configuring EC2 Auto Scaling and load balancing to improve application availability and scalability.
* Understood hybrid DNS integration using Route 53 Resolver, including inbound endpoints, outbound endpoints, and forwarding rules.
* Improved understanding of AWS resource deployment, configuration, monitoring, and cleanup.
